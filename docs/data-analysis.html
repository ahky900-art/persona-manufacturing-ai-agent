2. KOSHA 실제 산업재해 사례

공식 CSV를 업로드하면 실제 사고 제목·개요·원인·예방대책을 분석합니다. KOSHA 원문을 자동으로 재배포하지 않으며, 사용자가 받은 공식 파일을 브라우저에서 처리합니다.

데이터 준비: 공공데이터포털의 제조업 업무상 사고사례 CSV(공개 페이지 기준 1,136행) 또는 SIF 아카이브 파일을 내려받아 업로드하세요. SIF 자료는 2016~2023년 중대재해 6,032건(제조업 등 2,573건 포함)이며 원문 변경금지 조건이 있으므로 원문은 수정하지 않고 분석용 태그만 별도로 생성합니다.

CSV 파일을 선택하면 분석합니다. UTF-8 또는 EUC-KR 인코딩을 지원하도록 처리합니다.

3. Persona → 산재 유형 → 산업현장 Risk 연결

아래 연결은 직무 전문성 및 사고사례의 위험 태그를 산업설비 위험 카탈로그와 연결한 지식 탐색 결과입니다. Persona가 사고확률을 높인다는 인과관계로 해석하면 안 됩니다.

Hugging Face와 KOSHA 데이터를 각각 불러오면 연결 분석이 표시됩니다.

4. 분석 방법과 해석상 한계

  • Persona 분류는 occupation, professional_persona, skills_and_expertise(_list), career_goals_and_ambitions 등 직무 관련 텍스트의 키워드 근거를 이용한 다중분류입니다.
  • 사고 유형 분류는 사고 제목·개요·원인·예방대책에서 위험 키워드를 찾는 규칙 기반 태깅입니다. 다중 태그이므로 유형별 합계가 사고 건수보다 클 수 있습니다.
  • 표본 데이터의 직무 비중은 전체 한국 노동인구의 직업분포나 제조업 종사자 분포로 해석할 수 없습니다. 데이터셋의 합성 생성 분포 및 표본 편향이 존재합니다.
  • KOSHA 사고사례는 사고가 발생한 사례만 포함하는 선택편향이 있습니다. 사고확률·위험 발생률을 계산하려면 정상 작업·비사고 데이터와 노출시간 분모가 추가로 필요합니다.
  • 산업설비 연결은 현재 Refractory의 설비별 손상 메커니즘 카탈로그와 안전 위험 카탈로그를 활용한 전문가 검토용 후보입니다. 센서 기반 실시간 감지나 검증된 인과모델은 아닙니다.
